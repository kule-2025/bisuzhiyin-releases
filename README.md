# BiSuZhiYin · 笔溯之印

> AI 驱动的网文创作工作台 — 从萌新到大神，一部年度大作的全链路伙伴。

## 项目价值

笔溯之印（BiSuZhiYin）是一款面向网文作者的桌面创作工具，融合 AI 大模型能力与系统化写作方法论，覆盖从灵感构思、大纲搭建、章节创作、精修润色到数据追踪的完整创作链路。

## 核心能力

| 模块 | 功能 |
|------|------|
| 作品管理 | 多作品并行、作品级定稿/快照/回滚 |
| 大纲系统 | 树形大纲、拖拽排序、一键生成章节 |
| 章节编辑 | 富文本编辑器、实时字数、专注模式、语法高亮 |
| AI 创作 | 多模型聚合、对话续写、风格仿写、润色精修、角色生成 |
| 角色管理 | 角色档案、关系图谱、出场统计、一致性检查 |
| 世界观 | 题材模板、设定关联、检索引擎 |
| 数据统计 | 写作趋势、质量分析、目标追踪、榜单监测 |
| 会员体系 | 四等级权益、额度管理、付费墙优雅降级 |
| 系统能力 | 本地加密存储、云同步、自动更新、开发者后台 |

## 下载与安装

### 最新版本：v0.11.6

- **Windows 安装包**：[BiSuZhiYin_0.11.6_x64-setup.exe](https://github.com/kule-2025/bisuzhiyin-releases/releases/download/v0.11.6/BiSuZhiYin_0.11.6_x64-setup.exe)（40.5 MB）
- 支持 **自定义安装路径**（NSIS installMode=both）
- 安装向导支持简体中文 / English

### 系统要求

- Windows 10 / 11（x64）
- WebView2 Runtime（系统通常已预装）
- 约 200 MB 可用磁盘空间

## 使用入口

1. 安装后启动「笔溯之印」
2. 注册/登录账号
3. 创建作品 → 搭建大纲 → 开始创作
4. 在设置中配置 AI 模型 API Key（支持自定义接入）
