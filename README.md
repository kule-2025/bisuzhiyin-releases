## 产品简介

笔溯之印是面向网文创作者的 IP 全链路 AI 桌面创作工具，覆盖从小说创作到影视改编、条漫漫剧、视频制作的完整内容生产链路：

- **小说创作**：智能大纲、角色设定、世界观构建、章节续写、去AI味质控
- **影视剧本**：小说转剧本、分镜拆解、场景编排、对白优化
- **条漫漫剧**：剧本转条漫、分镜生成、台词排版、漫剧制作
- **视频制作**：漫剧转视频、素材管理、多模态模型接入、成片导出
- **智能体蜂群**：多角色AI协作、专家模板、RAG知识库、工作流编排
- **数据本地存储**：所有作品与设定仅存于本地，断网可用，永不丢失

## 系统要求

- 操作系统：Windows 10 / Windows 11（64位）
- 运行时：WebView2 随系统自带
- 磁盘空间：约 200MB
- AI 功能：需用户自行配置 API Key（支持 DeepSeek、智谱、硅基流动、Ollama 等）
