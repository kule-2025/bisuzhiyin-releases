## 为什么选择笔溯之印

网文创作不再是单打独斗。笔溯之印将 **AI 智能体蜂群** 与 **IP 全链路生产** 融为一体，让你从一个灵感出发，一路产出小说、剧本、条漫到视频成片。

- 小说创作：智能大纲、角色设定、世界观构建、章节续写、去 AI 味质控
- 影视剧本：小说一键转剧本、分镜拆解、场景编排、对白优化
- 条漫漫剧：剧本转条漫、分镜生成、台词排版、漫剧制作
- 视频制作：漫剧转视频、素材管理、多模态模型接入、成片导出
- 智能体蜂群：多角色 AI 协作、专家模板、RAG 知识库、工作流编排
- 数据完全本地：所有作品与设定仅存于你的电脑，断网可用，永不丢失

## 系统要求

- 操作系统：Windows 10 / Windows 11（64 位）
- 运行时：WebView2 随系统自带，无需额外安装
- 磁盘空间：约 200MB
- AI 功能：需自行配置 API Key（支持 DeepSeek、智谱、硅基流动、Ollama 等）
