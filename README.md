# 笔溯之印 BiSuZhiYin

> AI 驱动的网文创作工作台 — 桌面应用

**最新版本**：v0.11.7（2026-10-12）

## 简介

笔溯之印是一款面向网文作者的桌面创作工具，集成 AI 辅助写作、质量检测、IP 改编、多平台发布与变现追踪等核心能力，帮助作者从创作到变现一站式完成。

## 核心功能

### ✍️ 核心写作
- 多模式编辑器（普通/高级/沉浸式专注模式）
- 章节管理、大纲树、版本时光机
- 实时字数统计、写作目标追踪
- 分屏参考（大纲/角色/世界观/文风）

### 🤖 AI 辅助
- AI 对话、续写、精修、去 AI 味
- 多模型管理与场景选模
- 流式输出、熔断故障转移
- 写作教练、敏感词检测、节奏优化

### 📊 质量检测
- 四维质量评分（去 AI 味/爽点/情绪/逻辑）
- 逻辑扫描、读者模拟、爆款公式分析
- 风格画像、原创性检测
- 发布前质量校验与趋势追踪

### 🌍 世界观与角色
- 世界观条目 CRUD 与 AI 提取
- 角色档案、关系图谱、出场统计
- 一致性检测（AI + 规则双引擎）
- 知识图谱与写作提示

### 🎬 IP 改编
- 小说→剧本→分镜→条漫→视频 全链路
- 三阶段状态机（seg1→seg2→seg3）
- 镜级精修五态流转
- DAG 调度与成本熔断
- 素材资产管理与生成队列

### 📤 发布与变现
- 多平台适配导出（番茄/起点/晋江等）
- 发布记录与变现数据回流
- 商业化仪表盘（稿费估算/趋势）
- 成长体系（等级/成就/挑战/目标）

### 🔧 系统能力
- 本地 SQLite 加密存储（AES-256-GCM）
- 数据备份与恢复
- 自动更新（minisign 签名校验）
- 事件总线与任务队列
- Swarm 多 Agent 协作

## 下载安装

### Windows
- **系统要求**：Windows 10/11 x64，WebView2 Runtime
- **安装方式**：下载 `BiSuZhiYin_<版本>_x64-setup.exe`，双击运行
- 安装向导支持选择安装位置（当前用户/所有用户）

### 自动更新
应用启动后自动检查更新，检测到新版本时提示下载安装。更新包经过 minisign 签名校验，确保安全可靠。

## 隐私与安全

- 所有数据存储在本地 SQLite 数据库，使用 AES-256-GCM 加密
- 密码使用 Argon2id 哈希存储
- API 密钥加密保存于系统密钥链
- 不收集用户隐私数据，不上传创作内容至云端
- 更新包经过数字签名校验
