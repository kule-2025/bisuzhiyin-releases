# 笔溯之印 BiSuZhiYin

> AI 驱动的网文创作工作台 — 桌面应用

**最新版本**：v0.11.21（2026-10-28）

## 简介

笔溯之印是一款面向网文作者的桌面创作工具，集成 AI 辅助写作、质量检测、IP 改编、多平台发布与变现追踪等核心能力，帮助作者从创作到变现一站式完成。

## 核心功能

### ✍️ 核心写作
- 多模式编辑器（普通/高级/沉浸式专注模式）
- 章节管理、大纲树、版本时光机
- 实时字数统计、写作目标追踪
- 分屏参考（大纲/角色/世界观/文风）

### 🤖 AI 辅助
- AI 对话、续写、精修、去 AI 味
- 多模型管理与场景选模
- 流式输出、熔断故障转移
- 写作教练、敏感词检测、节奏优化

### 📊 质量检测
- 四维质量评分（去 AI 味/爽点/情绪/逻辑）
- 逻辑扫描、读者模拟、爆款公式分析
- 风格画像、原创性检测
- 发布前质量校验与趋势追踪

### 🌍 世界观与角色
- 世界观条目 CRUD 与 AI 提取
- 角色档案、关系图谱、出场统计
- 一致性检测（AI + 规则双引擎）
- 知识图谱与写作提示

### 🎬 IP 改编
- 小说→剧本→分镜→条漫→视频 改编流水线（视频生成当前支持可灵 Kling / Runway / Pika / 通义万相 DashScope 等 4 家真实模型，更多接入中；前期改编阶段为辅助工具，需逐段人工确认）
- 三阶段状态机（seg1→seg2→seg3，seg1 为确定性离线拆解已实现；改编各阶段均为辅助工具，需逐段人工确认）
- 镜级精修五态流转（Draft→Refining→Refined→Finalized→Published，禁止跳态，支持回退）
- 生成队列调度与成本熔断
- 素材资产管理与生成队列

### 📤 发布与变现
- 多平台格式适配导出（番茄/起点/晋江等；平台 API 直连发布待各开放平台端点开放后接入）
- 发布记录归档与变现数据记录（数据由本地发布记录聚合带入；平台侧收入需手动录入）
- 商业化仪表盘（变现数据记录与趋势，收入需手动录入）
- 成长体系（等级/成就/挑战/目标）

### 🔧 系统能力
- 本地 SQLite 加密存储（AES-256-GCM）
- 数据备份与恢复
- 自动更新（minisign 签名校验）
- 事件总线与任务队列
- Swarm 多 Agent 并发编排（步骤状态机 + 限流故障隔离）

## 订阅与授权

- **免费版**：单设备使用（1 台），基础写作与 AI 辅助功能
- **专业版**：多设备使用（2 台），解锁去AI味、云同步、知识库、发布中心等付费功能
- **终身版**：多设备使用（3 台），专业版全部功能 + 永久更新
- 设备数上限经前后端严格校验，超出时提示绑定设备已满

## 下载安装

### Windows
- **系统要求**：Windows 10/11 x64，WebView2 Runtime
- **安装方式**：下载 `BiSuZhiYin_<版本>_x64-setup.exe`，双击运行
- 安装向导支持选择安装位置（当前用户/所有用户）

### 自动更新
应用启动后自动检查更新，检测到新版本时提示下载安装。更新包经过 minisign 签名校验，确保安全可靠。

## 隐私与安全

- 所有数据存储在本地 SQLite 数据库，使用 AES-256-GCM 加密
- 云端账号密码使用 bcrypt 哈希存储（绝不明文落盘）；本地数据库密钥派生使用 Argon2id
- API 密钥加密保存于系统密钥链
- 不收集用户隐私数据；本地数据默认不上云，仅在用户主动开启云同步时，章节正文经加密通道上传至云端加密存储
- 更新包经过数字签名校验
